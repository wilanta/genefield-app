# GeneField 0.1.2

Rilis Windows x64 ini menyertakan penyempurnaan Tur Terpandu dengan 24 langkah dan 14 tugas latihan, penjelasan profil/detail kandidat, serta petunjuk yang menyesuaikan ruang layar. Profil baru memakai Bahasa Indonesia; pilihan bahasa tetap dapat diubah melalui Settings.

Latihan memakai layanan analisis dan penyimpanan asli. Model `final-v1`, protokol inferensi, dan database referensi tetap mengikuti baseline beku. Hasil aplikasi merupakan dukungan keputusan, bukan jaminan hasil F1 atau persetujuan ilmiah/pemulia.

Installer: `GeneField_0.1.2_x64-setup.exe`. WebView2 diperlukan untuk menjalankan aplikasi.

Validasi engineering lokal:

- 135 tes aplikasi dan 4 tes database referensi lulus.
- Pemeriksaan TypeScript, build frontend produksi, dan pemeriksaan format onboarding lulus.
- Smoke test executable release lulus: startup profil baru, dataset asli, Line Explorer, versi native 0.1.2, serta mulai/keluar tur; tidak ada WebView page exception.
- Verifikasi 645 hash runtime, hash database referensi, dan materi lisensi 444 paket lulus.

Bukti pengujian installer versi terdahulu tetap merujuk versi yang tercantum pada masing-masing laporan.

Smoke test menjalankan executable hasil build; pemasangan installer 0.1.2 pada mesin lain belum diuji. Tidak ada workflow CI GitHub pada saat rilis ini disiapkan.
